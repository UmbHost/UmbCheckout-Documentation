# 🛒 UmbCheckout Documentation

{% hint style="info" %}
These pages document **UmbCheckout 17 for Umbraco 17**.\
\
For UmbCheckout 1.x on Umbraco 10 or 13, choose **UmbCheckout 13** in the version menu at the top of the page.
{% endhint %}

{% hint style="warning" %}
UmbCheckout 17 is licensed by annual subscription, and every running instance of a production site needs a license. See [What's new in 17](getting-started/whats-new-in-17.md) and [Licensing](getting-started/licensing.md).
{% endhint %}

UmbCheckout is an eCommerce solution for Umbraco 17 integrated with [Stripe Checkout](https://stripe.com/docs/payments/checkout).

If you need a lightweight eCommerce solution for a site powered by Umbraco 17 then UmbCheckout will allow you to make use of the Stripe Checkout service with minimal coding required.

Once the nuget package is installed it's completely possible to integrate it using the Views area of the Umbraco backoffice!

### Who These Docs Are For

**The documentation is aimed at developers** who have a basic understanding of Umbraco and at least an understanding of the Razor syntax.

The best place to start is the [Getting Started](getting-started/overview.md) section for details how to install and carry out the initial configuration.

**Before you can use this package you will need a** [**Stripe account**](https://dashboard.stripe.com/register)**.**

### Where To Get Help

If you require further assistance please take a look at the [issue tracker](https://github.com/UmbHost/UmbCheckout/issues).

If you have a license with an active support subscription and require further assistance please [open a ticket in UmbPanel](https://www.umbpanel.io).
